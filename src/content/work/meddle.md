Meddle is an intelligent operating system for healthcare. I led design across brand and product. That meant defining the visual language, building the design system and shaping how the product behaves, on the surface and underneath.

## Scope

The work runs from the brand identity down to the technical foundations. The visual language is built on the Meddle wordmark, a dark-first colour system and Mona Sans VF. It reads as confident and clinical without feeling sterile.

The design system starts as W3C DTCG tokens for colour, spacing, border radius and type. Those feed Figma Variables, which feed a TypeScript React component library across fourteen files. Code Connect mappings keep Figma and the code in step.

## Approach

Clinicians and operators bring real pressure to the screen. A healthcare OS has to absorb that rather than add to it. So the system leans toward generous spacing, restrained motion and a hierarchy that doesn't need interpreting. The tokens carry those decisions, which means any team building on Meddle starts with them by default.
